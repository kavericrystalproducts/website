# Kaveri Crystal Products — GitHub Pages

Upload the CONTENTS of this folder to the ROOT of your GitHub repository.

The repository root must contain:
index.html
catalog.html
blogs.html
checkout.html
404.html
robots.txt
sitemap.xml
site.webmanifest
assets/
data/
products/
blogs/

No backend is required.

Custom domain:
https://kavericrystalproducts.com

After enabling GitHub Pages, add the custom domain under:
Repository → Settings → Pages → Custom domain

Then configure the DNS records at GoDaddy using the records GitHub shows.

Submit the sitemap in Google Search Console:
https://kavericrystalproducts.com/sitemap.xml
