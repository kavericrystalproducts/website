# SEO setup

Replace `https://kavericrystalproducts.com` with the real GoDaddy domain before launch.

## Blogger
For this GitHub Pages store, I recommend **not using Blogger for the main blog**. The site now has 60 individual static blog URLs under `/blogs/`, each with unique title, description, canonical, Open Graph/Twitter tags and Article JSON-LD. This gives full SEO control without adding another platform.

## Included
- robots.txt
- sitemap.xml with home, catalog, 250 product URLs and 60 blog URLs
- 404.html
- site.webmanifest
- favicon
- canonical URLs
- meta descriptions
- robots directives
- Open Graph + Twitter cards
- Product JSON-LD
- Article JSON-LD
- unique static product/blog pages
- mobile viewport

## Google Search Console
After connecting the real domain, verify it in Search Console using Google's DNS TXT record and submit `https://kavericrystalproducts.com/sitemap.xml`.

## Keywords
I did not rely on `meta name="keywords"`; Google does not use that tag for ranking. Focus on useful content, unique titles/descriptions, clean URLs, internal links, structured data, image alt text and speed.
